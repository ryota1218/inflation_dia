# 01 要求定義書（v1.0 承認待ち）

> 工程：要求分析（ウォーターフォール第1工程）
> 状態：**承認待ち**

## 1. 目的・背景

日常組の企画で使われていた「パーク（能力）」の仕組みを Minecraft Java Edition で再現する。
パークを取得すると手に入るダイヤの数が増えていく（インフレする）、マルチプレイ用のミニゲームを作る。

## 2. 利用者

| 項目 | 内容 |
|---|---|
| 想定プレイ形態 | マルチプレイ（サーバー） |
| 参加人数 | **4人**（将来は人数を増やせるようにしたい） |
| 運営者 | 管理者がコマンドでゲームを開始し、リスポーン地点などを設定する |

## 3. ゲームのルール概要

- **個人戦**
- 管理者がコマンドを実行するとゲームが始まる
- 開始コマンドの種類で、次の2つのモードを選ぶ

| モード | 勝利条件 |
|---|---|
| 時間制限モード | 制限時間が終わった時点で、ダイヤの獲得数が最も多いプレイヤーの勝ち |
| 目標個数モード | 目標の個数に最初に届いたプレイヤーの勝ち |

- **PvP あり**。死んでもペナルティはない（基本ルールの場合）
- 死んだら、管理者が設定した地点にリスポーンする
- 遊べる範囲に制限はない

## 4. ダイヤの扱い（スコア方式）

- ダイヤは**アイテムとしては出現しない**。サーバー側で数を記録するスコアとして扱う
- 手に入れるきっかけ（ダイヤ鉱石を掘る、敵を倒すなど）が起きた瞬間に、サーバーが持っているパークを考慮して獲得数を計算し、スコアに加える
- 獲得したときは、アイテムを出す代わりに**演出（エフェクト）**を表示する
- 獲得数に**上限はない**

## 5. パーク（能力）

### 5.1 取得

- ゲーム中、**一定時間ごと（3分または5分）**にパークを取得する

### 5.2 系統

パークは、ダイヤを手に入れるきっかけ・効果ごとに次の5つの系統に分ける。
個々のパークの中身は「パーク定義書」（別紙・後日作成）で決める。

| 系統 | 概要 |
|---|---|
| 敵を倒す系 | 敵（モブ）を倒すとダイヤが手に入る／増える |
| プレイヤーを倒す系 | 他のプレイヤーを倒すとダイヤが手に入る／増える |
| ダイヤを掘る系 | ダイヤ鉱石を掘ったときのダイヤの数が増える |
| ステータス系 | プレイヤーのステータス（体力・速さなど）が変わる |
| その他 | 上の4つに入らないもの（最も範囲が広い） |

## 6. 機能要求

| ID | 要求 | 優先度 |
|---|---|---|
| F-01 | 管理者がコマンドでゲームを開始できる（時間制限モード／目標個数モード） | 必須 |
| F-02 | 管理者がリスポーン地点を設定できる | 必須 |
| F-03 | 一定時間ごと（3分または5分）にプレイヤーがパークを取得する | 必須 |
| F-04 | ダイヤを手に入れるきっかけが起きたとき、サーバーがパークを考慮して獲得数を計算し、スコアに加える | 必須 |
| F-05 | ダイヤはアイテムとして出さず、獲得したときに演出を表示する | 必須 |
| F-06 | プレイヤーごとのダイヤの数を記録し、勝敗を判定する | 必須 |
| F-07 | ゲームが終わったら結果を表示する | 必須 |
| F-08 | 5つの系統のパークを、あとから追加しやすい仕組みにする | 必須 |

## 7. 範囲外（やらないこと）

- 幸運やシルクタッチ付きのつるはしで掘ったときの対応
- 日本語以外の表示
- 1.20.1 以外のバージョンへの対応（将来対応する可能性はある）
- 遊べる範囲の制限（ワールドボーダーなど）
- 死んだときのペナルティ（基本ルール）

## 8. 非機能要求・制約

| ID | 内容 |
|---|---|
| C-01 | **サーバー側だけで動くこと**。プレイヤーに何かを配布したり、クライアントにインストールさせたりしない（バニラのクライアントのまま参加できる） |
| C-02 | 対象バージョン：**Minecraft Java Edition 1.20.1** |
| C-03 | 形式：**Paper のプラグイン**、または **Forge の Mod**（基本設計の工程で決める） |
| C-04 | 表示言語：日本語のみ |
| C-05 | 4人で問題なく遊べること |
| C-06 | ダイヤの獲得数の計算はサーバー側で行う |

## 9. 完成の基準

- ミニゲームとして、開始 → パーク取得 → ダイヤ獲得（数が増える） → 終了・結果表示 までを通して遊べること

## 10. 要件定義で決めること

- パークを「ランダムで配る」か「いくつかの候補から選ぶ」か
- パークを取得する間隔（3分か5分か）を設定で変えられるようにするか
- ダイヤの数の表示方法（画面右側のスコアボードなど）
- 演出（エフェクト）の具体的な中身
- 制限時間・目標個数の初期値
- 個々のパークの詳細（別紙「パーク定義書」）
